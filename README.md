# Учебная совместная работа над кодом в реальном времени

Это **самостоятельный демонстрационный проект для курсовой Леры** «Организация совместной работы над кодом в реальном времени с использованием коммуникационных функций». Он не связан с другими курсовыми и репозиториями.

Проект содержит маленький модуль `notes.py`, десять тестов `unittest` и последовательность действий для живого совместного сеанса. Его назначение — дать команде безопасные исходные файлы, чтобы продемонстрировать подключение, обсуждение и совместное редактирование. **Сам архив не доказывает, что совместный сеанс был проведён.**

## Локальная проверка

Требуется Python 3.10 или новее. Из корня папки:

```bash
python -m unittest discover -s tests -v
```

## Сценарий для двух участников

1. Организатор открывает папку проекта в VS Code, проверяет, что в ней нет секретов и персональных данных, запускает Live Share и приглашает знакомого участника. Ссылку не публикуют открыто.
2. Гость подтверждает доступ, открывает `notes.py`, показывает строку с функцией `pending_titles` и задаёт вопрос через выбранный канал (встроенные функции, если доступны, или внешний чат/звонок).
3. Организатор и гость обсуждают возможное расширение (например, функция поиска по названию). Обязательна фиксация, кто делает правку и кто проверяет поведение.
4. После согласованной правки оба смотрят результат запуска тестов.
5. Организатор завершает Live Share; итог записывается в `SESSION_PROTOCOL.md` или в сообщение коммита.

Состояние доступности инструментов необходимо перепроверять на дату защиты: Live Share находится в режиме поддержки; JetBrains Code With Me постепенно выводится из эксплуатации в 2026–2027 годах.

## Публикация на GitHub

Сначала создайте **отдельный репозиторий Леры**, затем загрузите туда **содержимое распакованного ZIP, сохраняя папки**. Шаблон GitHub Actions запускает **только 10 тестов Python**, а не проверяет реальную синхронную совместную работу. На момент создания архива никакая ссылка на репозиторий Леры не утверждается.
